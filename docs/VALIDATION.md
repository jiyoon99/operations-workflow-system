# 공개본 검증 기록

검증 대상: 2026-09-09에 반영한 최신 코드와 공개용 명칭 변경.

## 실행 환경

- Windows, Python 3.14.4, 별도 가상환경.
- 운영 데이터가 없는 임시 DB에서 테스트.
- 백그라운드 수집 비활성화.
- 화면은 가상 데이터로 생성하고 Microsoft Edge에서 확인.

### 전체 회귀 테스트

첫 `unittest discover` 실행은 1,940건 중 1,930건 통과, 8건 실패, 2건 건너뜀으로 종료됐다. 공개용 명칭과 예시 값 변경으로 발생한 문자 길이·주소·업데이트 내역 관련 항목은 수정 후 32건의 집중 테스트를 통과했다.

기존 회귀 항목이던 셋팅 실적 설명, 기간 실적의 외부 수기판매 중복 제거, 자산 상세의 판매 전표 표시도 수정 후 3건의 집중 테스트를 통과했다.

최종 전체 회귀 재실행은 1,940건 모두 통과했고 2건은 실행 환경 조건에 따라 건너뛰었다. 실행 시간은 1,467.924초였다.

## 범위

외부 쇼핑몰·택배·문자·기존 관리 시스템의 실제 인증정보를 사용한 운영 호출은 수행하지 않는다. 과거 저장소의 검증 설명을 이번 버전의 통과 결과로 재사용하지 않는다.
